# Workflows

This world is the home for skills that Uzo uses.

It holds local master copies of reusable skills, including skills created from scratch, skills adapted from other people's work, and skills brought in directly for use in personal workflows.

The `skills/` directory is the first place skill work should happen. Local copies are created, edited, reviewed, and treated as the source version before anything is synced outward to global agent locations.

Global sync targets may include Codex, Claude, and Gemini/Antigravity skill directories, but this workspace remains the local home base for the skill collection.

## Structure

- `skills/` - local master copies of reusable skills
- `Documentation/` - supporting notes and workspace documentation
- `CLAUDE.md` - canonical workspace contract and operating instructions
- `AGENTS.md` - compatibility wrapper for agent runtimes
