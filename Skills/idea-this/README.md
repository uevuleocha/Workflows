# Idea This - Adoption Guide

Captures dictated ideas as numbered inbox entries in a per-subject folder `Archive/Live/Ideas/<Subject>/1.) Ideas.md` (Mode A, subject inferred or stated) and works a named idea by running `inspect` then `set-the-stage` (Mode B), with a Buzz variant that mirrors the idea — number and subject first — into the workspace Ideas channel (Mode C).

## Related skills

- Pairs with `finalize-idea`, which moves a completed idea to `1.) Finalized Ideas.md`.
