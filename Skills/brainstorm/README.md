# Brainstorm

Uzo's capture-first Brainstorming mode explores ideas warmly, interviews one decision at a time, checkpoints every answer, and converges on a user-approved North Star. Active `_chivita` captures become `_fini` only through the paired finalizer.

## Related skills

- `finalize-brainstorm` — required lifecycle partner for evidence-based closure.
- `for-dummies` — conditional dependency for plain-language clarity tests.
- `analogy` — conditional dependency for analogy-based explanation.
- `green-light` — permits a named implementation while Brainstorming remains active.

## Optional artifact formats

Pair with `html-this` or `pdf-this` for HTML-only or PDF-only human-readable artifacts while this skill retains content and workflow ownership.
