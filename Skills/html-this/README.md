# HTML This

Creates, converts, inspects, and verifies polished self-contained HTML durable artifacts. It converts PDF pages into accessible, page-faithful HTML while embedding the exact PDF bytes, and recovers Markdown from embedded or semantic sources without taking lifecycle ownership from the producing skill. Canonical Agent Provenance is rendered as exactly one accessible, responsive `Field | Value` table while the exact native source remains recoverable. Normal creation requires canonical provenance in the source or through the structured provenance input, rejects native-plus-structured ambiguity, and limits explicit exemptions to excluded operational or schema-sensitive inputs.

## Related skills

- Pairs with `pdf-this` and shares its durable-format protocol.
- May be co-invoked with durable-artifact creators and lifecycle finalizers.
- Uses the host PDF runtime (`pypdf` and Poppler) for PDF-to-HTML conversion.
