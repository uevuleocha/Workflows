# HTML This

Creates, converts, inspects, and verifies polished self-contained HTML durable
artifacts. It converts PDF pages into accessible, page-faithful HTML while
embedding the exact PDF bytes, and recovers Markdown from embedded or semantic
sources without taking lifecycle ownership from the producing skill.

## Related skills

- Pairs with `pdf-this` and shares its durable-format protocol.
- May be co-invoked with durable-artifact creators and lifecycle finalizers.
- Uses the host PDF runtime (`pypdf` and Poppler) for PDF-to-HTML conversion.
