# Git Diff — Adoption Guide

Read-only Git status and diff reporting: explicit rename-on/off totals, correct porcelain rename parsing, and an always-on submodule pointer table in submodule-bearing repositories. It never stages, commits, or mutates the repo.

## Related skills

- `stage-commit-push` — the mutating counterpart: deterministic stage/commit/push once the diff has been reviewed.
