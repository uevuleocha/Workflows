# Debug — Adoption Guide

Command-triggered Debug mode (#UzzysBugsBeGone): structured bug intake, a confirmed bug list, evidence-first investigation, ask-before-edit safety, surgical product-code blocks, and focused verification. Explicit invocation only (`/debug`). Persistent mode — emits a `Mode = Debug` footer until exited.

## Related skills

- `inspect` — the lighter check: verifies a just-applied code batch or audits an artifact without entering a persistent debugging mode.
- `green-light` — approval protocol for applying the fixes Debug proposes.
## Deterministic table dependency

Adopt `markdown-table-aligner` with this skill. It supplies the deterministic final padding pass for file-based Markdown tables; the portable rule remains the content and fallback contract.
