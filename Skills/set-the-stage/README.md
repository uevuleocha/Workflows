# Set The Stage

`set-the-stage` gives a concise, evidence-based briefing on what remains for the work currently in context. It works from conversation, pointed-at material, or relevant durable artifacts and uses one section per logical subject. Durable artifacts are optional context and are never created, edited, or linked by this skill.

## Related skills

- `workspace-setup` — uses `set-the-stage` to present setup/parity findings before executing any workspace changes. `workspace-setup` owns the audit and orchestration; `set-the-stage` owns the briefing shape.
- `inspect` — reads or evaluates a target when deeper target review is needed.
- `plan-this` — turns remaining implementation work into a durable plan when the user requests one.
- Artifact lifecycle skills — remain responsible for updating or finalizing any durable artifact referenced by the briefing.
