# Buzz Agent Manager

Checks seven Buzz agent facts across the panel, roster document, and routing digest. It verifies Claude effort and pinned models, checks package freshness when requested, prepares new agents, records confirmed app changes, and reconciles drift toward a user-named authority. Buzz itself is read-only. The former `buzz-agent-setup` phrases route here.

Related skills: `tread-lightly` (mandatory on every run), `exact-model-confirmation-gate` for durable writes, `markdown-table-aligner` for edited tables, and `buzz-channel-description` for channel descriptions.
