# Wiki Sync

Maintains an existing schema-driven workspace wiki autonomously. A plain invocation runs `workspace-full`; narrower runs require an explicit user scope. It reconciles every declared source identity, bridges a missing coverage contract only from unambiguous roots already written in the schema, synthesizes safely without routine approval stops, refreshes navigation and logs, maintains a forward-only unresolved-verification page, and verifies that sources stayed unchanged.

The bundled read-only Python helper supports file identities and semantic immediate-directory bundles without guessing roots, page types, or taxonomy. Historical groups always receive mine-and-fold plus light provenance; any full-page suggestion is reported after completion and requires a later explicit user instruction.

## Related skills

- `wiki-this` — creates the initial wiki, schema, source-root declaration, and workspace pointers.
- `markdown-table-aligner` — validates Markdown tables at the file-ownership boundary.

## Deterministic table dependency

Adopt `markdown-table-aligner` with this skill. It supplies the deterministic final padding pass for file-based Markdown tables; the portable rule remains the content and fallback contract.
