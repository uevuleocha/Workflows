# Finalize Brainstorm

Evidence-first lifecycle partner for `brainstorm`. It closes one exact active
`_chivita` capture only after the North Star, shared understanding,
contradictions, flags, and user acceptance are verified, then moves it to
Historical as `_fini`.

## Related skills

- `brainstorm` — required interview, capture, helper, and reopen owner.

## Optional artifact formats

Pairs with `html-this` and `pdf-this` so every existing format sibling is
finalized together without changing the owning lifecycle gate.
