# New Workspace

Use `/new-workspace` to turn a fresh folder into a minimal local Git workspace after confirming its identity. Bundled templates and a guarded Python helper create the contract files, base folders, empty ignore file, and initial commit while preserving existing files.

Related skills: `workspace-setup` provides full standards parity afterward; `initialize` handles chat-session intake. Neither is required by the bootstrap helper. Python 3.10+ and Git are required.
