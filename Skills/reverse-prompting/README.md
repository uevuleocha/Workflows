# Reverse Prompting — Adoption Guide

Forces the agent to ask clarifying questions before starting work: it surfaces its own assumptions, the user disambiguates, and only then does it proceed. Invoked with `/reverse-prompting`, "ask me questions first", or clear equivalents. Chat-first: no files are created by the questioning itself.

## Related skills

- None required. Pairs naturally with `prompt-contracts` when the clarified scope should harden into a 5-part spec.
