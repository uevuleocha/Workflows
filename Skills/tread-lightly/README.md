# Tread Lightly

Protects secrets and sensitive data during `.env`, configuration, credential,
log, Git, and related file operations. It minimizes access, suppresses secret
values, prevents unnecessary persistence or transmission, and displays a
turn-scoped `Tread Lightly` mode footer whenever active.

## Related skills

- None required. The one-response footer lifecycle mirrors `initialize`, but
  Tread Lightly activates explicitly or automatically on each sensitive turn.
