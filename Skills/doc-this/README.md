# Doc This — Adoption Guide

Creates or updates durable documentation in the nested Live Documentation tree (`Archive/Live/Documentation/<Category>/<Subject>/`), honoring an explicit category or inferring a sensible broad one and applying the workspace house style with per-Subject numbering. Personal, Resources, and Articles remain useful examples, not an exhaustive category list. Invoked with `/doc-this` or a clear ask for durable documentation.

## Related skills

- None required. Sibling of the durable-artifact `-this` family (`plan-this`, `task-this`, `prompt-this`, `report-this`), each owning its own artifact type.

## Optional artifact formats

Pair with `html-this` or `pdf-this` for HTML-only or PDF-only human-readable artifacts while this skill retains content and workflow ownership.
## Deterministic table dependency

Adopt `markdown-table-aligner` with this skill. It supplies the deterministic final padding pass for file-based Markdown tables; the portable rule remains the content and fallback contract.
