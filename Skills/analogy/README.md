# Analogy — Adoption Guide

Re-explains whatever topic the user points at using one or more concise
analogies. Invoked with `/analogy` or clear equivalents ("explain with an
analogy"). Chat-only: it creates no files and changes nothing.

## Related skills

- `say-more` - requires this skill on every run and combines its analogy method
  with `for-dummies`; ship and install all three together.
- `for-dummies` — sibling: analogy explains *sideways* by comparing to another
  thing; for-dummies explains *downward* by simplifying the thing itself.
- `brainstorm` — may call `analogy` conditionally when a comparison would make
  an emerging idea easier to understand.
