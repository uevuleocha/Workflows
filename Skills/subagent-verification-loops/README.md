# Subagent Verification Loops — Adoption Guide

Independently verifies an existing artifact through a reviewer-and-resolver loop, then reports confirmed findings without automatically applying changes. Explicit invocation only (`/subagent-verification-loops`).

## Related skills

- `agent-chatrooms` / `stochastic-multi-agent-consensus` / `model-chat` — the multi-agent family siblings (discussion, polling, and API-debate variants).
- `inspect` — the single-agent audit alternative for lighter checks.

## Optional artifact formats

Pair with `html-this` or `pdf-this` for HTML-only or PDF-only human-readable artifacts while this skill retains content and workflow ownership.
