# LTNEY — Adoption Guide

"LETS TALK NO EXECUTIONS YET." A persistent discussion mode: answer, reason, and inspect read-only, with no file writes, no mutating commands, no product code, and no validation/build/test runs. Every response carries a `Mode = LTNEY` footer until the user explicitly exits.

## Related skills

- `green-light` — the scoped execution override: it supersedes LTNEY for the named greenlit task only, while LTNEY stays active around it.
