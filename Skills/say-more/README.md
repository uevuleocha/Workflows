# Say More - Adoption Guide

Explains more about whatever the user points at. It defaults to a short, clearer explanation and uses a moderately longer mode when explicitly asked or when invoked again for the same context. It never turns added detail into storytelling or an unbounded lecture.

## Related skills

- `for-dummies` - required: every run uses its plain-language simplification.
- `analogy` - required: every run includes its concise comparison method.

Ship and install all three skills together.
