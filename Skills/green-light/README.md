# Green Light — Adoption Guide

Permission-and-delivery protocol: explicit invocation (`/green-light`,
"greenlight", "go ahead") means the agent has approval for the named task and
should proceed without re-asking, while preserving the project contract's
safety rules and surgical code-delivery style. It is scoped to the named task
— never a blanket bypass.

## Related skills

- `ltney` — the discussion-only mode green-light supersedes for a named task.
- `plan-this` / `task-this` — the artifacts a greenlight commonly executes
  against.

## Optional artifact formats

Passes a co-invoked `html-this` or `pdf-this` request through to the approved
durable-artifact producer while preserving that producer's ownership.
