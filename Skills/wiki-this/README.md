# Wiki This

Sets up a schema-driven plain-Markdown wiki in the current workspace. It helps the user choose source roots and a context-appropriate taxonomy, creates the wiki scaffold, and adds root contract pointers without touching source files or creating an Obsidian vault. It adapts the established Hub schema as an example, surfaces the wiki-follows-sources track/ignore choice, and confirms any proposed batching before an optional first sync. Historical-record treatment is also proposed per detected group and requires explicit user agreement.

## Related skills

- `wiki-sync` — maintains and ingests an existing schema-governed wiki.
