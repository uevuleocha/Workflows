# For Dummies — Adoption Guide

Re-explains the user-referenced topic in dead-simple, jargon-free terms, as if
for a beginner or young child. Invoked with `/for-dummies`, "dumb it down",
"ELI5", or clear equivalents. Chat-only: no files, no changes.

## Related skills

- `analogy` — sibling: for-dummies explains *downward* by simplifying the
