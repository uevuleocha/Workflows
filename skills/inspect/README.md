# Inspect — Adoption Guide

The general "check this for me" workflow. Mode A verifies a recently applied
code batch (any language) and syncs it into the session's working context;
Mode B audits any file, skill, document, or artifact for mistakes, issues,
consistency, or things to learn/adapt. Report-first: it does not edit unless
separately authorized.

## Related skills

- `debug` — the escalation for full bug diagnosis; inspect stays a
  single-pass check.
- `green-light` — approval protocol if the inspection's suggested corrections
  should then be applied.
