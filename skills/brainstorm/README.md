# Brainstorm — Adoption Guide

Enters Brainstorming mode: structured, collaborative, no-code-first thinking
around a problem, tool, workflow, architecture, or prompt-engineering target.
Explicit invocation only (`/brainstorm`). It is a persistent mode — every
response carries a `Mode = Brainstorm` footer until the user exits.

## Related skills

- None required. Pairs naturally with `plan-this` or `task-this` when a
  brainstorm graduates into durable work.
