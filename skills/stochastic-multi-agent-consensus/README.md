# Stochastic Multi-Agent Consensus — Adoption Guide

Polls independent agents with controlled framing variations, aggregates their
structured answers, and reports consensus, divergence, uncertainty, and
outliers. Explicit invocation only (`/stochastic-multi-agent-consensus`).

## Related skills

- `agent-chatrooms` — role-based discussion instead of framing-varied polling.
- `subagent-verification-loops` — the reviewer-and-resolver verification
  sibling.
- `model-chat` — the script-backed, API-driven debate variant.
