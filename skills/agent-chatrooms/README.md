# Agent Chatrooms — Adoption Guide

Runs a structured discussion among independent agents with distinct roles,
then synthesizes consensus, disagreements, and a recommended decision.
Explicit invocation only (`/agent-chatrooms`).

## Related skills

- `stochastic-multi-agent-consensus` — polls agents with controlled framing
  variations instead of role-based discussion.
- `subagent-verification-loops` — the reviewer-and-resolver verification
  sibling.
- `model-chat` — the script-backed, API-driven debate variant.
